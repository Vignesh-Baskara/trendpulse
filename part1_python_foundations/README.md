
# TrendPulse – Part 1: Python Foundations & Data Structures

## 1. Project Overview

This project analyses YouTube Trending Video Statistics
using core Python concepts and data structures.

## 2. Countries Used

- United States (US)
- Great Britain (GB)
- India (IN)

## 3. Dataset

Dataset: Trending YouTube Video Statistics.

Files:
- USvideos.csv
- GBvideos.csv
- INvideos.csv
- categories.csv

## 5. Tools and Dependencies

- Python
- Google Colab
- Pandas
- NumPy

Install dependencies:

pip install -r requirements.txt

## 6. How to Run

1. Open trendpulse_part1.ipynb in Google Colab.
2. Ensure the data files are available in the data folder.
3. Run all notebook cells from top to bottom.

## 7. Data Source

Trending YouTube Video Statistics dataset.
The dataset is publicly available on Kaggle.
